# R001 – Black-Box QA & UX Review: Portfolio Web Application

## Overview

This case study presents a structured black-box QA and UX evaluation of a publicly accessible portfolio web application.

The objective is to assess system quality from an external perspective, focusing on user experience, clarity of purpose, and observable behavior — without access to source code or internal systems.

## Review Scope

- Public UI interaction only
- No backend or code access
- No security testing or probing
- Evaluation based on real user flows and perception

## Key Focus Areas

- First impression & value clarity
- Navigation and information architecture
- UX consistency across devices
- Performance perception
- Error handling & edge cases
